# Project plan

## Strategy

Run an eight-week founder cohort that sells structure around freely available study resources: weekly live teaching, AI support, original practice, parent visibility, and regional accountability.

## Why a validation MVP

The next 30–45 days should answer whether families will register, attend a webinar, complete a diagnostic, pay a country-aware founder price, attend weekly, use the tutor, and value reports. Product depth matters only after those behaviors appear.

## Included

Public conversion pages, forms, webhook-ready lead capture, tutor demo, mock student/admin views, resource placeholders, and launch documentation.

## Intentionally excluded

Authentication, database persistence, full LMS features, automated grading, complex payments, video hosting, production analytics, and a partner reporting backend.
